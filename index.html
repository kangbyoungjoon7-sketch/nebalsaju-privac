2. 앱이 접근하는 정보

사용자가 Google 계정으로 동의하면 앱은 다음 권한을 요청합니다.

  • youtube.upload: 운영자 채널에 영상을 올립니다.
  • youtube.readonly: 채널 이름, 구독자 수, 영상 수, 조회수 등 채널 정보를 읽습니다.
  • youtube.force-ssl: 운영자가 올린 영상의 제목·설명·썸네일을 수정하고, 댓글을 달거나 답글을 답니다.

앱은 위 권한으로 운영자 본인의 채널 데이터만 다룹니다. 다른 사람의 채널이나 개인 정보에는 접근하지 않습니다.

3. 저장하는 정보

  • OAuth 토큰(접근 토큰·갱신 토큰): 운영자 PC의 _secret\token.json 파일에만 저장합니다. 외부 서버로 보내지 않습니다.
  • 업로드 기록(영상 제목, 영상 ID, 업로드 시각): 운영자 PC의 게시 로그 파일에 저장합니다.

앱은 Google 계정의 비밀번호를 받거나 저장하지 않습니다. 로그인과 동의는 Google 화면에서만 이루어집니다.

4. 제3자 제공 및 처리 위탁

앱이 수집한 정보는 Google의 YouTube Data API 호출에 필요한 범위에서만 사용합니다. 그 밖에 제3자에게 제공하거나 판매하지 않습니다.

5. 보관 기간과 삭제

  • 토큰 파일은 운영자가 인증을 해제하거나 파일을 삭제할 때까지 보관합니다.
  • Google 계정 설정(myaccount.google.com/permissions)에서 언제든 앱의 접근을 취소할 수 있습니다. 취소하면 토큰은 더 이상 쓸 수 없습니다.

6. Google API 서비스 사용 고지

이 앱은 Google API 서비스를 사용합니다. 사용에 따라 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
